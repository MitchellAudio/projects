# Sound System Documentation

Purpose
- Central place for documenting sound system designs, diagrams, wiring, and operational notes.

Structure
- `notes.md` — General notes and change log.
- `rack-diagram.md` — Rack diagram template.
- `power-diagram.md` — Power distribution template.
- `system-diagrams/` — Folder for image or diagram files.

How to use
- Add notes, diagrams, and links to relevant project files here.
