# CTS Certification Exams

This folder contains study materials for AVIXA CTS certifications.

## Certifications Covered

- **CTS** - Certified Technology Specialist (general)
- **CTS-I** - Certified Technology Specialist - Installation
- **CTS-D** - Certified Technology Specialist - Design

## Current Focus: CTS-I

The CTS-I certification validates expertise in:
- Installing and configuring AV systems
- System fabrication and rack building
- Setup, verification, and testing
- Project coordination and closeout
- Client training and documentation

## Prerequisites

- Must hold valid CTS credential before taking CTS-I
- Recommended: 3-4 years of installation experience

## Exam Information

- Computer-based testing at Pearson VUE centers
- Multiple-choice format
- No online proctoring available
