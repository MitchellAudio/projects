## 1. QSC and Q-SYS Brand Overview

### About QSC

- Founded **1968**, headquartered in Costa Mesa, California
- Originally a professional amplifier manufacturer; evolved into a full AV&C platform company
- Q-SYS platform launched circa **2010** as the company's software-defined AV strategy
- Acquired **Stem Audio** (conferencing microphone systems) and **QSC** expanded with camera and room tech
- Global distribution: sold through a channel partner model (dealers/integrators)

### Brand Architecture

| Brand | Focus |
|-------|-------|
| **QSC** | Parent company; professional audio amplifiers, loudspeakers |
| **Q-SYS** | Software-defined AV&C platform (the certification focuses here) |

### Company Positioning Statement

> Q-SYS is the platform for designing, deploying, and managing AV and control systems — from a single room to a global enterprise.

## 2. The Q-SYS Value Proposition

### Core Value Drivers

| Value Driver | What It Means for the Customer |
|--------------|-------------------------------|
| **Software-defined** | Upgrade functionality without replacing hardware |
| **Single platform** | Audio, video, and control in one system |
| **Cloud management** | Monitor and manage every system from anywhere |
| **Open ecosystem** | 3rd-party plugins and integrations |
| **Scalability** | Same platform for 1 room or 1,000 rooms |
| **Lower total cost of ownership (TCO)** | Fewer boxes, simpler service, remote management |

### The "One Platform" Pitch

Traditional AV installs require:
- Separate DSP unit (Biamp, BSS, Symetrix)
- Separate control processor (AMX, Crestron, Extron)
- Separate video switcher / matrix
- Separate monitoring/management tools

Q-SYS replaces all of these with **one platform** — reducing:
- Equipment cost
- Rack space
- Installation complexity
- Service call frequency

### TCO vs. First Cost

A common objection is Q-SYS upfront cost vs. commodity DSP. Counter with TCO:

| Factor | Traditional Multi-Box | Q-SYS Single Platform |
|--------|---------------------|----------------------|
| Hardware | DSP + Control + Video | Single Core |
| Programming hours | Each system programmed separately | Common design framework |
| Service visits | Per-device troubleshooting | Remote diagnostics via Reflect |
| Upgrades | Hardware replacements | Firmware updates |
| Training | Multiple platforms | Single platform for all rooms |

## 4. Competitive Landscape

> Note: Competitive information evolves frequently — verify current positioning with QSC partner resources before customer conversations.

### Primary Competitors

| Competitor | Product | Q-SYS Differentiator |
|------------|---------|---------------------|
| **Biamp** | Tesira, TesiraFORTÉ | Q-SYS: integrated control, single platform, cloud management |
| **Crestron** | DM NAX, NVX, NVX | Q-SYS: lower programming overhead, integrated DSP |
| **Extron** | DMP series, XTP | Q-SYS: stronger video routing, Reflect cloud management |
| **Symetrix** | Radius NX, Prism | Q-SYS: broader control ecosystem, enterprise scalability |
| **BSS / Harman** | BLU series | Q-SYS: open ecosystem, better cloud management story |

### Q-SYS Strengths vs. Competition

- **Integrated audio + video + control** in one platform (competitors often require separate boxes)
- **Q-SYS Reflect** cloud management at scale (enterprise differentiator)
- **Q-SYS Connect** for UC integration (Teams/Zoom) without third-party middleware
- **Open plugin ecosystem** — hundreds of third-party integrations
- **Same platform** for every market vertical (corporate, education, government, etc.)
- **Free Designer software** — low barrier to spec and prototype

### When Competitors Win

- Biamp Tesira: extremely high channel count analogue designs, some vertical-specific features
- Crestron: deeply embedded in buildings already running CrestronHomePro
- Extron: preference in government/DoD for security-certified products in some cases

## 6. The Q-SYS Sales Process

### Typical Sales Cycle

```
Awareness → Discovery → Solution Design → Demo/Proof of Concept → Proposal → Close
```

### Discovery Questions

Use these to qualify the opportunity and shape the solution:

**Scale:**
- How many rooms/spaces are involved? Single-site or multi-site?
- What is the target expansion plan over 3–5 years?

**Current state:**
- What AV systems are currently in place?
- What are the biggest pain points with the current system?
- How many service calls does the current system generate per month?

**UC and IT:**
- What UC platform does the organisation use (Teams, Zoom, WebEx)?
- Does IT manage AV, or is there a dedicated AV team?
- Are there network/security requirements we need to know about?

**Decision process:**
- Who is the technical decision maker? Who signs off on budget?
- Is this a competitive bid? Are there existing brand preferences?
- What is the timeline?

### Solution Mapping

After discovery, map pain points to Q-SYS features:

| Pain Point | Q-SYS Solution |
|-----------|---------------|
| Hard to manage multiple rooms | Q-SYS Reflect |
| Zoom/Teams meetings have audio problems | AEC + Q-SYS Connect |
| Staff can't operate the system | Intuitive TSC panel UCI |
| Multiple vendors, complex service | Single-platform Q-SYS |
| Expanding campus | Scalable Core architecture |

## 7. Demonstrating Q-SYS

### Demo Goals

1. Show how **easy** it is to build a design (Designer drag-and-drop)
2. Show the **UCI** — how a non-technical operator controls the room
3. Show **Reflect** — remote monitoring across sites
4. Show **integration** — one button starts a Teams meeting, adjusts lights, lowers screen

### Demo Environment Options

| Option | Best For |
|--------|---------|
| **Q-SYS Core Flex (software emulation)** | Remote/virtual demos, early-stage discovery |
| **Q-SYS tabletop demo kit** | In-person, hands-on demonstrations |
| **Reference installation** | Peer-to-peer site visits, late-stage evaluation |

### Key Demo Moments

- **"One click, everything happens"** — show a UCI button that triggers: display turns on, audio unmutes, Teams call connects (Q-SYS Connect)
- **"I can see every system in the world"** — Reflect dashboard showing all sites, with a simulated fault
- **"No programmer needed"** — drag a fader in Designer, explain it becomes a touchscreen control

### After the Demo

- Leave behind: Q-SYS Designer download link (free), case study matching their vertical, Reflect one-pager
- Follow-up: offer a design session with a solutions engineer to scope their specific rooms

## 8. Objection Handling

### "Q-SYS is too expensive"

**Response:**  
Q-SYS replaces multiple systems — DSP, control, video routing, and monitoring — with one. When you add up the cost of a traditional multi-box system plus the ongoing service and programming costs, Q-SYS often has a lower TCO over 5 years. Let me walk through a comparison for your specific project.

---

### "We already have Crestron/AMX everywhere"

**Response:**  
Q-SYS works alongside existing control systems through our open QRC protocol. Many customers run Q-SYS for audio/video processing and use their existing control system for room automation. Over time, many customers find they can simplify to Q-SYS-only as rooms refresh.

---

### "Our IT department won't allow another device on the network"

**Response:**  
Q-SYS is designed with IT in mind. It uses standard managed Ethernet with VLAN support, communicates outbound only over HTTPS for cloud management (no inbound firewall rules needed), and can be fully isolated on a dedicated AV VLAN. We have IT-friendly network specs and switch recommendations.

---

### "We're happy with Biamp / what we have"

**Response:**  
That's great — Biamp makes solid DSP. Where Q-SYS often wins is when customers want to add video routing, a UC integration layer, or centralised management across multiple rooms without adding separate control processors. If you have future rooms planned, it's worth looking at Q-SYS now before the next refresh.

---

### "We don't have a certified integrator"

**Response:**  
QSC has a network of Q-SYS certified integrators in your area. I can connect you with partners who have Q-SYS Level 1 or Level 2 certification. We also have a 'find a partner' tool on our website.

## 9. Licensing and Pricing Model

### Revenue Streams

| Item | Type | Who Buys |
|------|------|---------|
| Core hardware | One-time | Integrator/end user |
| I/O frames and peripherals | One-time | Integrator/end user |
| SIP license | One-time, per Core | End user |
| Video license | One-time, per Core | End user |
| Q-SYS Reflect | Annual subscription, per Core | End user (managed service or direct) |
| Training/certification | One-time fee | Integrators, end users |

### Pricing Considerations

- Q-SYS Designer is **free** — lower the barrier to evaluation and spec inclusion
- Hardware pricing is through the distributor/dealer channel — do not quote list price without checking current pricing
- Reflect subscriptions are a recurring revenue opportunity for managed service providers
- Bundle Core + I/O + peripherals + Reflect = complete room solution pricing

### Channel Model

```
QSC ──► Distributor ──► Dealer/Integrator ──► End Customer
                         (installs, programs)
```

- End customers do not buy direct from QSC (except some very large enterprise accounts)
- Sales reps support integrator partners and influence end-user decisions
- Spec the product into a project → integrator wins the bid → QSC earns the sale
