# Q-SYS Certification Pathway

Q-SYS is QSC's software-based audio, video, and control (AV&C) platform. This section tracks notes and study materials for the Q-SYS certification pathway.

## Certification Levels

| Level / Course | Name | Format | Audience |
|----------------|------|--------|----------|
| **Level 0** | Q-SYS Foundations | Free online (training.qsc.com) | Everyone; prerequisite for all |
| **Level 1** | Q-SYS Designer | Online + proctored exam | Integrators, programmers |
| **Level 2** | Q-SYS Advanced | Online + proctored exam | Experienced designers |
| **Architect** | Q-SYS Architect | Online + exam | Consultants, system designers |
| **Sales** | Q-SYS Sales | Online course | Sales engineers, resellers |
